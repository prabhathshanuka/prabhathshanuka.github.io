# Introduction to Algorithms

> **Learning objective:** Understand what an algorithm is and recognise the features of a well-defined solution.

## What is an algorithm?

An **algorithm** is a finite sequence of clear, ordered instructions used to solve a problem or complete a task.

An algorithm describes the logic of a solution. It is not tied to one particular programming language.

## Characteristics of an algorithm

A well-designed algorithm should have:

- **Clear instructions:** Each step should be precise and unambiguous.
- **A logical order:** Instructions should be arranged in the correct sequence.
- **An end point:** The algorithm should finish after a finite number of steps.
- **Defined input and output:** Where appropriate, the information entering and leaving the process should be clear.

## Example: Add two numbers

The following Python code implements a simple algorithm that adds two values:

```python
first_number = 25
second_number = 4

total = first_number + second_number
print(total)
```

The output is:

```text
29
```

## Remember

An algorithm is the **step-by-step solution** to a problem. A programming language is one way to implement that solution.
